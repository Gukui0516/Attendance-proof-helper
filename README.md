# 증빙 니가해

한글 설치와 서버 없이 실행하는 Windows용 교육 출결증빙 작성기입니다.

## 사용

`Attendance-proof-helper.exe`를 실행합니다. 강사/보조강사를 체크하고 이름, 교육장소, 교육실시ID를 입력합니다. 교육과정은 지정된 세 가지 중 선택하고 달력과 시/분 선택기로 일정을 입력합니다. 분은 00 또는 30만 선택할 수 있습니다.

사진 여러 장 추가 또는 붙여넣기로 모든 교시의 사진을 한꺼번에 넣습니다. 목록은 교시마다 전·중·후 3자리씩 늘어납니다. 사진을 선택하고 ↑ 앞으로 / ↓ 뒤로 버튼으로 위치를 바꾸며 교시 사이 이동도 가능합니다. 빈 자리부터 채우며 자리가 부족하면 교시를 추가하라는 안내가 나옵니다. 사진은 높이를 채우며 너무 넓은 사진은 좌우를 중앙 기준으로 자릅니다. 오른쪽에서 미리보기를 확인하고 현재 교시의 HWPX를 저장합니다. 원본의 두 번째 교육 프로그램 페이지도 보존합니다.

강사 표기는 `강사: 이름`, `보조강사: 이름`입니다. 두 역할을 모두 선택하면 왼쪽 제출자 선택에서 사용할 사람을 고릅니다. 제출자 이름은 입력한 이름과 자동으로 연동됩니다.

서명 이미지를 한 번 선택하면 흰 배경을 투명하게 처리해 이 PC의 `%LOCALAPPDATA%/AttendanceProofHelper/signature.png`에 저장하며, 다음 실행에서 자동으로 복원합니다. 서명은 제출자 옆 `(서명)` 글자와 겹쳐집니다. 필요할 때 서명 사용 체크를 끄거나 다른 이미지로 변경할 수 있습니다. 원본의 기존 서명 이미지는 복사하지 않습니다. 하단 확인 항목 세 개는 네에 동그라미가 표시됩니다.

파일명은 `교육실시ID_출결증빙자료_이름.hwpx`로 제안됩니다. Windows 파일명에 쓸 수 없는 `*` 등은 밑줄로 바꿉니다. HWP 저장은 지원하지 않습니다.

## 문서와 미리보기

원본 HWPX의 표, 셀 크기, 스타일을 보존하며 내용과 사진을 교체합니다. `rhwp` 0.8.6 로컬 실행 파일로 생성된 HWPX 자체를 SVG로 렌더링합니다. 앱은 HTTP 서버를 열거나 문서를 외부로 전송하지 않습니다. 미리보기는 한컴의 렌더러가 아니므로 설치 글꼴과 엔진 차이에 따른 글자 모양/줄바꿈 차이가 있을 수 있습니다. 한컴에서의 픽셀 단위 동일성은 검증하지 않았습니다.

## 개발

Python 3.12 환경에서 `python -m pip install -r requirements.txt`를 실행합니다. 사용자가 제공한 원본을 `template.hwpx`로 배치하고, https://github.com/edwardkim/rhwp/releases/tag/v0.8.6 의 Windows x86_64 배포본에서 `rhwp.exe`를 배치합니다. 원본 문서와 실행 바이너리는 Git에서 제외합니다.

실행: `python main.py`

검증: `python test_app.py build/test-output`

빌드: `./build.ps1 -Template C:\로컬양식\template.hwpx -Renderer C:\로컬엔진\rhwp.exe` (원본 파일명은 template.hwpx로 준비). 빌드 스크립트는 다른 도구의 DLL이 섞이지 않도록 PATH를 제한합니다.

## 라이선스

외부 라이브러리 고지는 `licenses` 폴더에 포함합니다. PySide6/Qt는 LGPLv3 조건으로 사용하는 동적 라이브러리입니다. 소스에서 별도 설치한 PySide6로 실행 및 재빌드할 수 있습니다. rhwp는 MIT 라이선스입니다.

## 글꼴과 달력

교육일자는 항상 표시되는 월별 달력에서 선택합니다. 좌우 화살표로 월을 바꾸고 선택한 날짜는 파란색으로 표시됩니다.

SVG의 글꼴 목록을 Qt가 잘못 처리하던 부분을 수정하여 설치된 원본 글꼴을 우선 적용합니다. 원본의 표 배경 #F2F2F2, 글자 크기, 테두리 서식은 그대로 보존합니다. 양식 확대는 미리보기만 확대하고 저장 문서의 용지 크기는 바꾸지 않습니다.

휴먼명조는 GitHub 공개/EXE 내장 허용 근거가 확인되지 않아 포함하지 않습니다. FONT-LICENSE-NOTES.md를 참고하세요. 글꼴 설치만으로 별도 앱 사용·재배포가 자동 허용되는 것은 아닙니다.

## 교시 탭

처음에는 1교시 탭으로 시작합니다. 상단 + 또는 Ctrl+T로 새 교시를 만들고 탭으로 미리보기를 전환합니다. 설정창의 `공통 설정`과 `개별 설정` 버튼을 누르면 각 영역을 접거나 펼칠 수 있습니다. 공통 설정에는 강사·보조강사와 이름, 교육장소, 제출자, 서명, 교육 월·날짜가 들어 있으며 모든 교시에 적용됩니다.

개별 설정에서는 같은 항목끼리 모아 표시합니다. 교육과정명 목록에 모든 교시, 교육실시ID 목록에 모든 교시, 시작·종료시간 목록에 모든 교시가 각각 표시되므로 탭을 바꾸지 않고 비교하며 수정할 수 있습니다. 증빙사진 전체 순서도 개별 설정 안에서 관리합니다. 새 교시는 과정·시간 기본값과 빈 ID·사진 자리 3개로 시작합니다.

× 또는 Ctrl+W로 닫습니다. 닫은 교시 복원 또는 Ctrl+Shift+T로 최근 10개까지 되돌릴 수 있습니다. 마지막 탭을 닫으면 새 빈 교시가 열립니다. 저장 버튼은 현재 교시만 HWPX로 저장합니다. 교시 번호는 문서 본문이나 파일명에 추가되지 않습니다. 앱을 종료하면 탭 작업 상태와 닫은 탭 기록은 사라지므로 각 교시 파일을 저장하세요. 서명 이미지는 기존처럼 다음 실행에도 유지됩니다.
