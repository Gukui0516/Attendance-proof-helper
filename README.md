# 증빙 니가해

디지털배움터 교육 사진 증빙 서류(.hwpx)를 만드는 Windows 데스크톱 프로그램입니다.
**한글(HWP)도, 인터넷도, 서버도 필요 없습니다.** 실행 파일 하나로 동작합니다.

원본 HWPX 양식의 XML을 그대로 두고 값과 사진만 갈아끼우는 방식이라, 서식·표·글꼴·
셀 크기가 원본과 같습니다. 2쪽의 교육 프로그램 표도 손대지 않습니다.

---

## 무엇을 하나

왼쪽에서 값을 채우면 오른쪽 미리보기가 바로 바뀌고, 그 상태 그대로 `.hwpx`로 저장됩니다.

### 공통 항목 — 모든 교시에 똑같이 들어감
강사 / 보조강사(체크 + 이름) · 교육장소 · 교육일자(월·일) · 제출자 · 서명 이미지

### 교시별 항목 — 같은 항목끼리 모아서 입력
교육과정명 · 교육실시ID · 시작/종료 시간 · 증빙사진

교시를 늘리면 각 묶음에 줄이 하나씩 늘어나므로, 탭을 오가지 않고 여러 교시를 나란히
비교하며 고칠 수 있습니다. 모든 묶음은 접었다 펼 수 있습니다.

### 교시 탭
미리보기 위쪽에 브라우저처럼 `1교시 ✕ | 2교시 ✕ | ＋` 탭이 있습니다. 탭을 누르면
미리보기가 그 교시로 바뀝니다. 새 교시는 앞 교시가 끝난 시각부터 이어지고, 과정은
1교시 에듀버스1 → 2교시 에듀버스2 → 3교시 에듀버스3 순으로 자동 지정됩니다
(에듀버스1·2는 1시간, 에듀버스3은 1시간 30분).

### 증빙사진
사진은 한 곳에서 받습니다. 파일을 **창 위로 끌어다 놓거나**, `사진 한번에 불러오기`로
여러 장을 고르거나, `Ctrl+V`로 붙여넣으면 **빈 자리부터 차례대로** 채워집니다.
목록에는 파일 이름만 나오고, 줄을 **끌어다 놓아 순서를 바꿉니다**. 교시 경계를 넘어서도
옮겨집니다.

`3장씩 (전·중·후)` / `2장씩 (전·중)` 배치 모드를 고를 수 있고, 모드를 바꾸면 넣어둔
사진이 새 순서로 다시 흘러갑니다. 자리가 모자라면 교시를 늘릴지 물어봅니다.

미리보기에서 사진을 클릭하면 **자르기 창**이 열립니다. 사진을 끌어 위치를 맞추고 휠로
크기를 조절하며, 밝은 틀 안쪽만 문서에 들어갑니다. 비율은 `칸에 꽉(1.08:1)` `1:1`
`3:4` `원본 비율` 중에 고르며, 어떤 값을 골라도 칸 비율을 넘지 않게 막아 두어
**세로로는 항상 꽉 차고 좌우로는 넘치지 않습니다.** 원본을 따로 보관하므로 몇 번이든
다시 자를 수 있습니다.

### 서명
서명 이미지를 한 번 올리면 흰 배경을 자동으로 지워 투명하게 만들고 여백을 잘라내
`%APPDATA%\출결증빙생성기\` 에 저장합니다. 다음 실행에도 그대로 남습니다.
제출자 이름 옆 `(서명)` 자리에 겹쳐 찍히며, 미리보기에서 **직접 잡고 끌어 옮기거나
모서리 손잡이·휠로 크기를 조절**할 수 있습니다(더블클릭하면 원래대로).

### 저장
`전체 교시 한번에 저장`은 폴더 하나를 골라 교시 수만큼 파일을 만들고,
`보고 있는 교시 저장`은 현재 교시만 저장합니다.
파일 이름은 `교육실시ID_출결증빙자료_이름.hwpx` 입니다.
`.hwp`(바이너리) 저장은 한글 없이는 만들 수 없어 지원하지 않습니다.

### 프리셋
`제대병원` 버튼을 누르면 교육장소와 3교시 구성(과정·시간)이 한 번에 채워집니다.
이미 입력한 교육실시ID와 사진은 건드리지 않습니다. 프리셋은 `app.py` 의 `PRESETS`에
한 줄 추가하면 버튼이 하나 더 생깁니다.

### 저장되는 값
공통 항목 · 교시 구성 · 사진 배치 모드 · 서명(이미지와 크기·위치) · 접어둔 묶음까지
`%APPDATA%\출결증빙생성기\config.json` 에 자동 저장되어 다음 실행에 복원됩니다.
**증빙사진은 저장하지 않습니다.** 교시마다 매번 다른 사진이라, 지난 사진이 남아 있으면
잘못 제출할 위험이 커서 일부러 뺐습니다.

## 실행 준비

### 1. 원본 양식 준비 (필수)

**이 저장소에는 원본 HWPX 양식이 들어 있지 않습니다.** 아래 두 가지 이유 때문입니다.

- 양식 자체가 배포처의 저작물입니다.
- 배포된 양식 파일 안에는 **작성자의 손글씨 서명 이미지와 기관 주소가 들어 있을 수
  있습니다.** 공개 저장소에 올릴 수 없는 개인정보입니다.

각자 받은 양식으로 한 번만 변환하면 됩니다.

```
python make_template.py 양식.hwpx
```

`template_data.py` 가 만들어집니다. 이 파일도 같은 이유로 `.gitignore` 에 들어 있으니
**커밋하지 마세요.** 양식의 구조가 다르면 어느 자리가 없는지 알려주고 멈춥니다.

### 2. 의존성

Python 3.12 기준입니다. 화면은 표준 라이브러리 `tkinter` 로 그리고, HWPX는 표준
라이브러리 `zipfile` 로 직접 만듭니다. 외부 의존성은 이미지 처리를 위한 Pillow 뿐입니다.

```
python -m pip install -r requirements.txt
python app.py
```

### 3. 실행 파일 빌드

```
.\build.ps1 -Template C:\경로\양식.hwpx
```

`make_template.py` 와 `make_icon.py` 를 돌린 뒤 PyInstaller로 `dist\증빙 니가해.exe`
(약 30 MB, 단일 파일)를 만듭니다.

## 어떻게 만드나

`hwpx_builder.py` 가 원본 `Contents/section0.xml` 에서 값이 들어갈 자리를 찾아
그 부분만 바꿉니다.

| 자리 | 방법 |
| --- | --- |
| 강사/보조강사 · 교육장소 | `paraPrIDRef="24"` 문단의 텍스트 교체 |
| 교육과정명 · 교육일자 · 제출자 | 해당 `<hp:t>` 교체 |
| 교육실시ID | 비어 있던 칸(`colAddr="4" rowAddr="1"`)에 문단 속성까지 넣어 채움 |
| 증빙사진 | 사진칸의 빈 문단에 `<hp:pic>` 삽입 (글자처럼 취급, 세로 21500 HWPUNIT) |
| 서명 | 원본의 `<hp:pic>` 을 새 이미지로 교체, 크기·위치는 조절값 반영 |

그 다음 `content.hpf` 매니페스트에 이미지 항목을 추가하고, `mimetype` 을 첫 항목·무압축
으로 두는 규칙을 지켜 zip으로 다시 묶습니다. 나머지 파일(header.xml, section1.xml 등)은
원본 그대로 복사합니다.

미리보기는 원본을 한컴에서 렌더링한 이미지에서 표의 선 위치를 mm 단위로 실측해 맞췄고,
글꼴 크기·표 머리 배경(`#F2F2F2`)·테두리 두께도 원본 서식 값을 읽어 반영했습니다.
다만 **한컴의 렌더러가 아니므로 글자 모양이나 줄바꿈이 조금 다를 수 있습니다.**
한컴에서의 픽셀 단위 일치는 검증하지 않았습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `app.py` | 화면 전체 (설정창, 미리보기, 자르기 창) |
| `hwpx_builder.py` | HWPX 생성 |
| `make_template.py` | 원본 양식 → `template_data.py` |
| `make_icon.py` | `assets/icon.png` → `app_icon.ico` + 창 아이콘 |
| `build.ps1` | 단일 exe 빌드 |

저장소에 올리지 않는 것: 원본 양식과 `template_data.py`, 생성된 아이콘 파일,
빌드 결과물, 그리고 모든 `.hwpx`.
